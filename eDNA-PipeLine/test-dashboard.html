eDNA Explorer Dashboard Test

Test 1: Check if the application is running

Open your browser and navigate to http://localhost:5173

You should see the eDNA Analysis Pipeline interface.

Test 2: Upload Sample Data

1. Click "Download Sample Data" to get a sample CSV file

2. Upload the sample data using the file upload interface

3. Click "Process Dataset" to proceed

Test 3: Process Data

1. Click "Start AI Analysis" to begin processing

2. Wait for the processing to complete

3. You should see processing steps with progress bars

Test 4: View Dashboard

1. After processing, navigate to "Biodiversity Assessment" tab

2. You should see:

  • Biodiversity metrics cards (Species Richness, Shannon Index, etc.)
  • Taxonomy composition charts
  • Diversity analysis tabs
  • Novel taxa clusters
  • Spatial distribution charts

Common Issues and Solutions

If charts are not showing:

  • Check browser console for errors (F12 → Console)
  • Ensure data has been processed successfully
  • Verify that processedData is not null

If dashboard is empty:

  • Make sure you've completed the data processing step
  • Check that the "analyze" tab is selected
  • Verify that processedData contains valid data

If processing fails:

  • Check that your CSV file has the required columns
  • Ensure data is in the correct format
  • Try with the sample data first
